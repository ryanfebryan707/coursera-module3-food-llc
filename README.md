# Food, LLC — Responsive Menu

A one-page responsive menu built for the graded portion of the [Module 3 Coding Assignment](https://github.com/jhu-ep-coursera/fullstack-course4/blob/master/assignments/assignment3/Assignment-3.md) in **HTML, CSS, and JavaScript for Web Developers**.

**Live page:** [Open the menu](https://ryanfebryan707.github.io/coursera-module3-food-llc/module3-solution/)

## Assignment requirements

| Requirement | Implementation |
| --- | --- |
| Bootstrap grid | `container-fluid`, `row`, and `col-xs-12` |
| Header | Scrollable Bootstrap navbar with **Food, LLC** brand |
| Mobile navigation | Three-bar toggle, full-width dropdown, Chicken / Beef / Sushi |
| Main heading | Centered with Bootstrap's `text-center` |
| Content | One tall, contrasting section for every viewport |
| Styling | Separate `css/styles.css`; no inline styles |
| Interaction | `js/script.js` handles menu accessibility and changes the one panel's content |
| Visual depth | CSS shadows give the panel and controls a subtle 3D effect |

The course solution is in [`module3-solution/`](module3-solution/). It includes a local copy of Bootstrap 3.4.1, its MIT license, and a focused [implementation guide](module3-solution/README.md). Open `module3-solution/index.html` locally without a build step.
