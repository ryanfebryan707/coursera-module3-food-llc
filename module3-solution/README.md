# Module 3 — Responsive Menu

A one-page solution for the graded part of the [HTML, CSS, and JavaScript for Web Developers Module 3 assignment](https://github.com/jhu-ep-coursera/fullstack-course4/blob/master/assignments/assignment3/Assignment-3.md).

## What is included

- A static, non-fixed Bootstrap 3 navbar branded **Food, LLC**.
- A mobile-only three-bar toggle and full-width menu with Chicken, Beef, and Sushi.
- A centered **Our Menu** heading using Bootstrap's `text-center` class.
- One tall, contrasting menu section inside `container-fluid`, `row`, and `col-xs-12`.
- Separate CSS and JavaScript files. Selecting a mobile item updates the one section while preserving the single-section graded layout.
- Subtle 3D depth from layered CSS shadows on the header, menu button, and content panel, without changing the required layout.
- Keyboard support for the mobile toggle, including Escape to close it.
